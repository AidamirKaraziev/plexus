# Начать — одна дверь в работу

Человек открывает сессию этой командой и больше ничего не выбирает
руками. Скилл смотрит состояние, спрашивает один раз — и передаёт работу
дальше.

Speak Russian to the user throughout.

**Своей работы у этого скилла нет.** Он не пишет код, не правит файлы
проекта, не заводит веток и не читает базу знаний. Он решает, что
следующее, и зовёт того, кто это делает. Всё, что он производит сам, —
один экран и один вопрос.

Бюджет на открытие: **не больше 4k токенов.**

## 1. Что читать

```
python3 ${CLAUDE_PLUGIN_ROOT}/lib/counters.py     # n/m по эпикам, следующий этап
python3 ${CLAUDE_PLUGIN_ROOT}/lib/streams.py      # эпики Сейчас/Дальше, передача
(cd vault && ls круги/)                            # открытые круги
git status --short | head -5
```

Больше ничего. Ни кода, ни заметок, ни подпланов: на этом шаге нужна не
полнота, а следующий шаг.

## 2. Четыре состояния

| что видим | что делаем |
|---|---|
| плана нет | сказать одной строкой и завести план — `/plexus:roadmap new`; дальше обычный ход |
| план есть, открытого круга нет | показать экран, предложить варианты, собрать задание — `/plexus:task` |
| круг открыт, есть незакрытые задачи | ничего не спрашивать: продолжить круг с первой незакрытой (§7 `/plexus:task`) |
| всё закрыто | сказать «нечего брать» и предложить следующее по плану |

Круг считается открытым, если в `круги/` в vault есть файл со `статус:
утверждено` и не все его задачи попали в раздел «Итог».

## 3. Экран открытия

Один блок моноширинного текста, без прозы вокруг. Пустой раздел
выбрасывается целиком.

```
ПРОЕКТ  skills · main · 23 сен

СЕЙЧАС  E06 Круг v1   4/5
        передача: 2026-09-22 · закрыт круг «работник делает сам»
        ⚠ незакрытая задача: обкатка на Astra

ДАЛЬШЕ  S03 ревьюер и вердикт
        S04 экран круга с ревью

ХВОСТЫ  2 файла не закоммичены
```

## 4. Один вопрос

`AskUserQuestion`, один раунд, до четырёх вариантов: незакрытая задача
открытого круга, следующий этап плана, что-то из «Дальше». Последний
вариант всегда — «другое, скажу сам». Описание каждого варианта — одна
строка, чем он отличается.

Круг уже открыт и в нём есть незакрытая задача — **вопрос не задаётся**:
человек выбрал это, когда утверждал круг. Продолжаем молча.

## 5. Передать работу

Выбор сделан — дальше работает не этот скилл:

- задача новая → `/plexus:task <формулировка>`: интервью до 100 % и файл
  задания. Экран открытия повторно не показывается;
- круг уже есть → раздача задач работникам, §7 `/plexus:task`;
- плана нет → `/plexus:roadmap new`, потом вернуться сюда.

Одна строка о том, что передали, — и всё.

## Никогда

- Не писать код и не править файлы проекта. Даже мелочь.
- Не заводить веток и дорожек для человека: он всегда в main.
- Не читать базу знаний и подпланы — только то, что в §1.
- Не задавать больше одного раунда вопросов: остальное спросит `/plexus:task`.
- Не решать за человека, какую задачу брать, если вариантов больше
  одного и выбор меняет работу.
