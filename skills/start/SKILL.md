# Начать — одна дверь в работу

Корень Плексуса — `${CLAUDE_PLUGIN_ROOT}`; в Codex эта строка не раскрывается — бери путь из строки контекста «корень Плексуса: …», а если её нет — папку на два уровня выше этого SKILL.md.

Человек открывает сессию этой командой и больше ничего не выбирает
руками. Скилл показывает дерево работы, спрашивает один раз (или берёт
выбор из аргумента) — и передаёт работу дальше.

Speak Russian to the user throughout.

**Своей работы у этого скилла нет.** Он не пишет код, не правит файлы
проекта и не читает базу знаний. Он решает, что
следующее, и зовёт того, кто это делает. Всё, что он производит сам, —
один экран и один вопрос.

Бюджет на открытие: **не больше 4k токенов.**

## 1. Что читать

```
python3 ${CLAUDE_PLUGIN_ROOT}/lib/экран_старта.py   # экран-дерево работы
git status --short | head -5
```

Больше ничего. Ни кода, ни заметок, ни подпланов, ни vault: на этом шаге
нужна не полнота, а следующий шаг.

## 2. Три вызова

| вызов | что делаем |
|---|---|
| `/plexus:start` | экран и один вопрос (§3, §4) |
| `/plexus:start auto` | `экран_старта.py --выбрать auto`, без вопроса |
| `/plexus:start E29` или `E29-S10` | `экран_старта.py --выбрать <id>`, без вопроса |

По аргументу экран не показывается. Ответ `--выбрать` — одна строка:
`круг «<имя>»` или `этап E29-S10`. Код 2 — нечего выбрать: показать экран
и одну строку причины, затем обычный вопрос (§4).

Плана нет — сказать одной строкой и завести: `/plexus:roadmap new`,
потом вернуться сюда.

## 3. Экран

Печатается как есть, одним моноширинным блоком, без прозы вокруг.
Номер `[N]` — для глаз; команда по номеру не выбирает.

## 4. Один вопрос

`AskUserQuestion` (в Codex — `request_user_input`; недоступен — один
вопрос текстом с вариантами), один раунд. Варианты:

- до трёх лучших свободных `[N]` в порядке `--выбрать auto`: свободный
  круг без ⚠ с наибольшей долей сделанного, потом свободные этапы без ⏸
  и без ⚠, потом остальные свободные;
- четвёртый — «Выбери сам».

Подпись варианта — id и короткое имя («E30-S01 Чек-листы»). Описание —
одна строка, чем отличается: «доделать начатое», «новый круг через
/plexus:task», «та же область, что у занятого», «N дней без движения:
закрыть или отложить».

«Другое» встроено в инструмент: человек пишет id или свою задачу.
Занятый круг (🔒, не «брошен?») в варианты не попадает. Если человек сам
ввёл его id — предупредить строкой и спросить, брать ли.

«Выбери сам» — то же, что `auto`: `--выбрать auto`.

## 5. Передать работу

- круг → `экран_старта.py --взять <круг>`; чужой свежий замок (код 2) —
  остановиться, сказать, кто держит, и спросить, брать ли. Затем
  `экран_старта.py --передача <круг>`: если там есть «Ждёт тебя» — это
  первый вопрос человеку, до чтения любых файлов. Дальше раздача задач
  работникам, §7 `/plexus:task`;
- этап без круга → `/plexus:task <этап>` (замок поставит task, когда
  заведёт круг);
- плана нет → `/plexus:roadmap new`, потом вернуться сюда;
- своя задача → `/plexus:task <формулировка>`.

Сразу после выбора (кроме «плана нет») завести ветку задачи:

```
python3 ${CLAUDE_PLUGIN_ROOT}/lib/ветка_задачи.py завести "<формулировка выбора>"
```

Формулировка — имя круга или «<id> <имя>». Вывод команды — одна строка,
её и сказать человеку: на какой ты ветке («ветка … заведена от main»,
«… уже была — продолжаем», «хвосты переехали на ветку»). Код 2 — ты на
чужой ветке задачи: выбор новой остановить и сказать то, что вернула
команда («ты на ветке <имя> — сначала /plexus:end»), ничего не брать и
замок не ставить. Строку `ВЕТКА` на экране показывает `экран_старта.py`:
`ВЕТКА  main` или `ВЕТКА  <имя> · задача <формулировка>`.

Одна строка о том, что передали, — и всё. Замок снимает `/plexus:end`,
не этот скилл.

## Никогда

- Не писать код и не править файлы проекта. Даже мелочь.
- Не заводить worktree для человека: его ветка живёт в его папке.
- Не читать базу знаний и подпланы — только то, что в §1.
- Не задавать больше одного раунда вопросов: остальное спросит `/plexus:task`.
- Не решать за человека, какую задачу брать, если вариантов больше
  одного и выбор меняет работу.
- Не снимать чужой замок и не брать занятый круг без явного «да».
- Не продолжать круг молча: каждый вход в сессию — экран, `auto` или id.
