# Закрыть — одна дверь из работы

Корень Плексуса — `${CLAUDE_PLUGIN_ROOT}`; в Codex эта строка не раскрывается — бери путь из строки контекста «корень Плексуса: …», а если её нет — папку на два уровня выше этого SKILL.md.

Человек заканчивает сессию этой командой. Скилл проверяет, показывает
итог и отдаёт текст коммита. Коммитит человек.

Speak Russian to the user throughout.

**Своей работы нет** — как и у `/plexus:start`. Проверку гоняют команды из
файла круга, знание раскладывает `/plexus:note`, дорожки убирает `${CLAUDE_PLUGIN_ROOT}/lib/уборка.py`.

## 1. Что читать

```
(cd vault && ls круги/)                            # открытый круг
python3 ${CLAUDE_PLUGIN_ROOT}/lib/уборка.py --сухой-прогон
git status --short
```

Открытого круга нет → одна строка «нечего закрывать» и, если есть
незакоммиченное, текст коммита. На этом конец.

## 2. Проверить, а не поверить

Для каждой задачи круга выполнить её `проверка:` — ту самую команду, не
похожую. `проверка: человек` — показать критерий и спросить одной
строкой.

Команда упала → задача уходит в итог с ✗ и строкой «почему». Чинить
здесь нельзя: это конец сессии, а не доделка. Не сошлось много — сказать
прямо, что круг не закрыт.

## 3. Итог

Экран — как в §7 `/plexus:task`: таблица задача · время · токены · окно ·
проверка, успешная задача одной строкой, разворачиваются только ✗ и ⚠.
Цифры берёт `lib/spend.py`, не человек и не работник. Тот же текст
уходит в раздел «Итог» файла круга.

Все задачи ✓ → файл круга переезжает в `архив/` внутри `круги/` в vault.

## 4. Знание

Предложить списком, что записать: решения из круга, найденные баги,
приёмы. Человек вычёркивает лишнее. Записывает `/plexus:note` — по заметке на
решение.

Ничего заметного не появилось — раздел пропустить молча.

## 5. Уборка и коммит

Показать вывод `--сухой-прогон` и спросить одной строкой: сносить?
Ответ «да» → `python3 ${CLAUDE_PLUGIN_ROOT}/lib/уборка.py`. Невлитое скрипт
не трогает сам.

Перед текстом коммита позвать `cd "${CLAUDE_PLUGIN_ROOT}/lib" && python3 аналитика.py
--порог`. «звать: нет» → раздел не показывать вовсе. «звать: да» →
спросить одной строкой с числом сигналов из вывода, звать ли
`/plexus:analyst`. Ответ «нет» ничего не ломает и порог не сбрасывает — идёт
сразу к тексту коммита.

Последняя строка сессии — текст коммита в стиле репозитория, готовый
к копированию. Человек не должен зависать на полпути.

## Никогда

- Не коммитить и не вливать ветки. Это делает человек.
- Не доделывать за работника упавшую задачу.
- Не писать в итог цифры, которых не дал скрипт.
- Не архивировать круг, в котором остались ✗ или ✋.
