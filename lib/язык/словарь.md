# Базовый словарь Плексуса: термины, которые одинаково читают скиллы, агенты и сторож.
Проектный словарь (`vault/словарь.md`) дополняет базовый; при совпадении термина действует проектный.

## Термины
| термин | значение | единица | запрещённые синонимы |
|---|---|---|---|
| круг | Один файл задания в `vault/круги/` с задачами; идёт одной веткой и одним замком. | — | таск, спринт, итерация |
| этап | Часть эпика, которая целиком помещается в одну сессию; в плане имеет id вида E29-S10. | — | фаза, шаг эпика |
| эпик | Крупная цель в плане `.claude/plan/roadmap.md`, нарезанная на этапы. | — | инициатива |
| работник | Агент, который делает одну выданную задачу круга и отчитывается четырьмя полями. | — | исполнитель, воркер, субагент |
| руководитель | Сессия, которая выдаёт задачи работникам, проверяет отчёты и решает, что делать дальше. | — | менеджер, оркестратор, главный |
| бриф | Текст задания работнику: цель, «готово, когда» и стопы до шагов. | — | промпт, постановка |
| readback | Первое сообщение работника: своими словами цель, «готово, когда» и стопы; работа начинается после слова «работай». | — | подтверждение, ack, пересказ |
| отчёт | Итог работника ровно в четырёх полях: ветка, сделал, не смог, проверка. | — | резюме, саммари |
| ветка задачи | Git-ветка человека, куда вливаются коммиты работников круга; не main. | — | фича-ветка |
| ветка работника | Git-ветка в дорожке работника; её коммиты руководитель переносит в ветку задачи. | — | — |
| дорожка | Отдельная рабочая папка работника (worktree) на ветке работника. | — | копия репозитория |
| окно контекста | Предел текста, который модель держит в одной сессии. | токены | буфер |
| лимит | Предел расхода, после которого работа стоит до сброса или решения человека; единицу называй всегда. | токены, часы или $ — одна в каждой фразе | квота |
| расход | Сколько токенов, часов и долларов потрачено на круг по ledger. | токены, часы, $ | затраты, стоимость |
| токены | Единица счёта текста модели, по которой считают окно, лимит и расход. | токены | — |
| база знаний | Папка `vault/` с заметками проекта: решения, модули, круги, словарь. | — | вики |
| стоп | Работа прекращается; продолжение только после ответа. | — | пауза, остановка, подожди |
| готово, когда | Проверяемое условие, при котором задача считается сделанной; к нему дана команда `проверка`. | — | критерий приёмки, DoD |
| проверка | Команда из задачи, которую работник прогоняет перед отчётом; её вывод идёт в отчёт. | — | — |

## Расплывчатые слова
| слово | чем заменить |
|---|---|
| база | «база знаний», «база данных» или «замер „до“» — назови какая |
| окно | «окно контекста» или «лимит N часов» — назови какое |
| вроде | факт с уликой или строка «предположение: …» |
| быстро | числом: «за N секунд» |
| много | числом с единицей: «N шт», «N токенов» |
| несколько | точным числом |
| немного | числом с единицей |
| примерно | числом и допуском: «N ± M» |
| около | числом и допуском |
| как правило | условием: «если X, то Y» |
| обычно | условием или частотой: «в N из M случаев» |
| иногда | условием или частотой |
| скоро | датой или часом |
| позже | датой или часом |
| по возможности | «обязательно» или «не делать» |
| и т.д. | полным перечнем |
| и так далее | полным перечнем |
| подходящий | названным критерием |
| нормальный | названным критерием |
| хороший | названным критерием |
| оптимальный | названным критерием и числом |
| ускорить | «снизить N до M единиц» |
| улучшить | «изменить X с A на B» |
| оптимизировать | «снизить N до M единиц» |
| поддержка | действием: «принимает», «читает», «пишет» |
| соответствующий | точным именем |
| определённый | точным именем |
| некоторый | точным именем |
